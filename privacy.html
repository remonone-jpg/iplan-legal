개인정보처리방침

시행일: 2026년 09월 03일 · 아이플랜(iPlan)

아이플랜은 서비스 제공에 필요한 최소한의 개인정보만을 수집하며, 이용자의 개인정보를 제3자에게 판매하지 않습니다.

1. 수집하는 개인정보 항목 및 목적

[직접 입력 정보]

  • 아이 이름, 생년월일, 성별, 알레르기 정보 — 맞춤 식단 분석 및 알레르기 경고 제공
  • 식단표 사진, 가정통신문 사진 — OCR 텍스트 추출 및 일정 분석
  • 아이 작품 사진 — AI 관찰 리포트 생성
  • 성장 기록(키, 몸무게), 치아 기록 — 성장 그래프 및 치아지도 제공
  • 마일스톤 기록, 작품 사진, 독서 기록 — 육아 기록 보관
  • 예방접종 기록, 영유아 검진 기록 — 건강 관리 정보 제공

[소셜 로그인 정보]

  • Google, Apple, 카카오 계정의 이메일, 고유 식별자, 닉네임(프로필 이름) — 회원 인증 및 계정 관리, 설정 화면의 계정 표시 (비밀번호는 수집하지 않습니다)

[자동 수집 정보]

  • 앱 이용 기록(기능 사용 횟수) — 무료/유료 기능 제한 관리
  • 구독 상태 및 무료체험 시작일 — 구독 서비스 제공
  • 기기 위치 정보(정확 위치 또는 대략 위치) — 내 주변 아이랑 장소 검색 기능 제공 시에만 사용되며, 사용자가 허용한 경우에 한해 수집됩니다
  • 방문 장소 정보 — 발자국 지도 기록 제공

2. 개인정보 보유 및 이용 기간

[비로그인 사용]

모든 데이터는 이용자의 기기(로컬 저장소)에만 저장되며, 앱 삭제 시 자동으로 삭제됩니다.

[로그인 사용 (클라우드 동기화)]

데이터는 Supabase 서버에 암호화되어 저장됩니다. 회원 탈퇴 또는 데이터 삭제 요청 시 지체 없이 삭제되며, 관련 법령에 따라 일정 기간 보관이 필요한 경우 해당 기간 이후 완전히 삭제됩니다. 가족 공유 기능은 현재 준비 중이며, 제공 시 공유 범위를 본 방침 개정으로 고지합니다.

이용자는 앱 설정 화면의 "모든 데이터 초기화" 기능으로 이 기기에 저장된 데이터를 언제든지 삭제할 수 있습니다(비로그인 사용 시 모든 데이터가 이에 해당). 로그인 시 클라우드에 저장된 데이터의 삭제는 회원 탈퇴를 통해 처리됩니다.

3. 제3자 서비스 이용 및 개인정보 국외 이전

서비스별 전송 데이터:

  • Naver Clova OCR: 이미지 데이터 (식단표, 가정통신문) — 텍스트 추출
  • Anthropic Claude API: 이미지 및 텍스트 데이터
    • 식단표 사진(원본) — 메뉴·날짜 추출
    • 아이 작품 사진(원본, 여러 장) 및 아이 나이 — 관찰 리포트 생성
    • 가정통신문 OCR 텍스트 — 일정 추출
    • 식단 텍스트 — 영양 분석, 레시피 추천
    • 아이 이름과 식단 — 아이별 식단 비교 조언 생성
    보관: 전송된 내용은 30일 이내 자동 삭제되며 AI 모델 학습에 사용되지 않습니다. 다만 이용정책 위반으로 분류된 경우 최대 2년까지 보관될 수 있습니다.
  • Supabase: 사용자 계정 및 저장 데이터 — 클라우드 저장 및 인증
  • Google/Apple/카카오: 이메일, 고유 식별자 — 소셜 로그인 인증
  • Apple In-App Purchase: 구독 결제 정보 — 결제 처리
  • 한국관광공사 TourAPI: 없음 (공공 데이터 조회만) — 아이랑 탭 정보 제공
  • 공공데이터포털: 없음 (공공 데이터 조회만) — 시설 정보 제공
  • 카카오 책 검색 API: 검색어 — 독서기록 도서 검색
  • 카카오 로컬(지오코딩) API: 장소명·주소 — 발자국 기록의 좌표 변환

전송된 데이터는 각 서비스의 처리 정책에 따라 분석 목적으로만 사용되며, 별도로 저장되지 않습니다.

※ 개인정보는 아래와 같이 국외로 이전됩니다. 이용자는 회원가입 시 이에 동의한 것으로 간주됩니다.

· 저장: Supabase — 호주(계정 정보 및 앱에 저장한 기록)

· 경유: 아이플랜 자체 API 서버 — 미국(OCR·AI 요청 중계, 별도 저장하지 않음)

· 처리: Anthropic Claude API — 미국(이미지 및 텍스트 분석, 30일 이내 자동 삭제)

· 처리: Naver Clova OCR — 한국(이미지 텍스트 추출)

※ 아이플랜은 이용자의 개인정보를 제3자에게 판매(Sell)하지 않습니다.

4. 건강 정보 보호

아이플랜은 알레르기, 성장 기록, 예방접종, 영유아 검진 기록 등 건강 관련 정보를 수집합니다. 이 정보는 다음 원칙에 따라 엄격하게 보호됩니다.

  • 건강 관련 정보는 앱 내 기능 제공 목적으로만 사용됩니다.
  • 마케팅, 광고 목적으로 사용되거나 데이터 브로커 등 제3자에게 판매되지 않습니다.
  • 건강 정보는 보호자의 계정에 귀속되며, 보호자의 명시적 동의 없이 외부로 공유되지 않습니다.

5. 아동 개인정보 보호

아이플랜은 만 14세 미만 아동이 직접 가입하거나 개인정보를 입력하는 서비스가 아닙니다. 앱은 보호자(학부모)가 자녀의 육아 정보를 관리하는 목적으로 설계되었습니다.

  • 아이플랜은 아동으로부터 직접 개인정보를 수집하지 않으며, 만 14세 미만 아동의 서비스 직접 이용을 허용하지 않습니다.
  • 아동의 개인정보는 보호자의 동의 하에 입력되며, 보호자는 언제든지 앱 내에서 해당 정보를 삭제할 수 있습니다.
  • 아동 관련 데이터(이름, 생년월일, 성장 기록 등)는 보호자의 계정에 귀속되며, 외부와 공유되지 않습니다(가족 공유 기능 제공 시, 보호자가 명시적으로 설정한 경우에 한해 공유되며 별도 고지합니다).
  • 보호자는 설정 화면의 "모든 데이터 초기화"(기기 내 데이터) 또는 회원 탈퇴(클라우드 데이터)를 통해 아동 관련 정보를 삭제할 수 있습니다.

6. 이용자의 권리

  • 개인정보 열람, 수정, 삭제 요청 가능
  • 앱 설정 내 "모든 데이터 초기화"로 기기 내 데이터 삭제 가능 (클라우드 데이터는 회원 탈퇴로 삭제)
  • 로그인 사용자: 설정 화면 내 회원 탈퇴 시 서버에 저장된 모든 데이터 지체 없이 삭제
  • 개인정보 처리에 대한 동의 철회 가능
  • 위치 정보 수집은 기기 설정에서 언제든지 거부 가능
